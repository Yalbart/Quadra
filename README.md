# Quadra
OpenGL game, sandbox

08.07.2026.
----------------------------------------------------------------------------------------------------------------------
After 2 months of subtle work on this project, i've learned a whole lot. As it's my first "serious" project, i've wanted it to at least be written in a "nice" and "proper" way. Now of course it's far from finished or perfect, it's obvious from the way it's written and programmed that a newbie and an amateur built it, but i'm still happy with how it's turning out. :)

On the topic of AI usage on this project, AI has been used to help with finding bugs, and also to check if certain parts of code are valid and written properly. Everything , including actual de-bugging and writting every single line of code has been done BY ME and by MY TWO HANDS. I am not and am not planning to use an agent.

This game is made using c/c++ libraries and header files: the freeglut GLUT library, GLEW for OpenGL stuff, stb_image and stb_truetype for texture work and on-screen text (TBA)...
Minimal GLSL for minimal shader work, this is a semi-hard 2d platformer that's played with collisions and simple counters.
Very simple , but weirdly fun enough, with a lot of potential for multiple levels and possible little story elements later.

The idea is for the player character to be a little mouse, which in pursuit of oh-so-tasty cheese, goes down a rabbit-hole (or a mouse-hole, you could say) and quickly goes on an adventure to escape the sewer and cave systems it got itself into.
The first and right now only playable level has some of the ideas i had for multiple levels and different areas combined into one level, split into 4 quadrants. This "demo" of sorts will serve as my college dissertation, and i shall use it as such, until further notice. I might fork this project eventually and make a full game, or simply remake it using a proper game engine.
